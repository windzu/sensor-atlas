FIELD PROTOCOL / V0.2

先统一条件，再观察差异。每项结果都对应一段可回放的数据。

开始前：统一测试条件 设备 · 环境 · 数据 · 显示

先做干净窗口、无遮挡、无明显雨雾的基准采集，再改变距离、角度或单一环境条件。比较不同设备时，使用相同目标、安装高度、测试路线与回放设置；无法一致的配置要在报告中说明。

检查项需要记录或确认的内容
设备与配置型号、序列号、固件、驱动版本、帧率、扫描模式、回波模式、厂家滤波设置；无法取得的字段标注「未知」
安装与视场安装高度、俯仰角、目标方位；先确认近场盲区、视场裁切和安装遮挡
目标与环境目标尺寸、材质／颜色、朝向、天气、光照、路面；反射率未测量时不填写估计值
录制数据优先保留原始包与传感器配置，同时保留解析点云；只有点云时说明数据链路与已启用的处理
时间与完整性包名、传感器时间戳与包内相对时间、点云 topic／坐标系；检查丢帧、丢包及诊断告警
回放显示固定视角、点大小、着色字段、色标范围、ROI、单帧／累积时长；运动片段不用于厚度或拖尾定量

每次采集包含条件变化前后的连续片段，关键距离或异常位置短暂停留，便于逐帧检查。自然条件无法控制时，记录实际情况，不把天气不同的两段结果直接归因于设备差异。

判定与复核约定

结果使用条件
未观察到异常在已记录工况和检查片段内未出现所查现象，不能外推为所有工况均无异常
观察到异常异常可在连续片段中复核，已用现场照片或基准排除真实物体；注明偶发／持续及复现条件
待复核仅单帧异常，或受遮挡、运动、丢包、显示设置影响，原因尚不能确认
未测试场景未采集或数据不可用，单独标注原因，不记作通过

有效检测距离记录「连续可分辨／间歇可分辨／不可分辨」，测距精度记录实际观察或统计值，不强行套用异常项的结论。临界结果至少再次采集同工况片段；复测不一致时保留全部结果与差异。本文的距离档位、复核方法属于项目约定，不代表行业标准。

对比连续帧中的轮廓，而不是只数几个孤立点。

02 / 选择场景

用什么测

人、车、骑行者、锥桶，只看正面。记录衣着／车身颜色、目标尺寸和锥桶反光条情况；同一轮对比使用同一目标。

复核要点

排除视场边缘、近场盲区、遮挡和显示累积影响。不同衣着、车身材质或光照的结果分别记录；本项不评价侧面与背面。

03 / 录包与回放

现场怎么做

  1. 从近到远连续录包，逐步改变目标与 LiDAR 的距离，保持正面朝向和视场内方位基本一致，避免其他物体遮挡。
  2. 按 5m 档位检查并短暂停留；距离取目标 ROI 点云的代表距离，测量口径保持一致。目标不出点时，使用地面标记或独立测距记录所在位置。
  3. 回放先看单帧，再看连续片段。逐档记录轮廓连续可分辨、间歇可分辨或不可分辨，不能用长时间累积补成的轮廓代替单帧表现。
  4. 临界处再靠近、远离一次，保留最后连续可分辨档位与后一档的对照；若场地结束时仍可分辨，记作「至少达到该距离，受场地限制」。
04 / 观察与判定

什么结果才有依据

目标必须具备可辨轮廓，几个孤立点不算有效。只在部分帧可辨时记录为间歇可分辨，不计入连续有效距离。报告按 5m 档位给出结果，避免把档位读数写成更高精度的测量。

05 / 保留证据

报告里体现什么

四类目标的尺寸／外观、最远连续可分辨档位、后一档表现、复测结果、场地上限；附临界前后同视角截图、包名和相对时间段。

基础性能

测距精度

沿平面法向，观察点云厚度

测距随机误差及通道差异会让平面点云呈现厚度。现场先用厚度评价点云离散程度，观察其随距离的变化；墙面薄并不能证明没有整体偏移。若要评价绝对测距偏差，需另加独立距离真值及其测量不确定度。

01 / 理解原理

测距随机误差及通道差异会让平面点云呈现厚度。现场先用厚度评价点云离散程度，观察其随距离的变化；墙面薄并不能证明没有整体偏移。若要评价绝对测距偏差，需另加独立距离真值及其测量不确定度。

↳

墙面厚度反映离散程度；整体测距偏差需要独立真值。

02 / 选择场景

用什么测

平整、无纹理起伏的墙面和清晰墙角。选择非玻璃、非强反墙体，尽量保持接近正入射；避开墙面边缘、门窗、管线和墙角混合像素区。

复核要点

运动畸变、安装振动、墙体不平、斜入射和跨帧累积都会使墙面变厚。发现整体偏移时另做真值对照，不能沿用「无偏移」假设；未做真值检查时在报告中写明。

03 / 录包与回放

现场怎么做

  1. 保持安装姿态，靠近或远离墙面、墙角并录包；在 10、20、30m……附近停稳，保留静止片段，距离从目标点云读取。
  2. 使用相同 ROI、单帧显示、点大小和视角。从侧视图看平面厚度，墙角两面墙分别检查，不把拐角混合点纳入墙面统计。
  3. 有数据处理条件时，对每个静止帧独立拟合平面，计算点到平面的有符号残差，报告 P95−P5 厚度、标准差、ROI 点数与有效帧数；拟合／剔除规则固定并保留。
  4. 在连续帧中检查厚度是否稳定、有无通道分层，并记录变稀／缺点。只有目视结果时标注「目视估计」，不从截图点大小推算厘米值。
04 / 观察与判定

什么结果才有依据

比较不同距离下相同统计口径的厚度与稳定性。每帧重新拟合后的残差主要反映平面内离散，不能用它证明绝对距离正确，也不能直接当作厂家的测距精度指标。

05 / 保留证据

报告里体现什么

按每 10m 一行记录点云距离、ROI／统计方法、厚度、通道分层、墙角表现、稀疏／缺点、有效帧数；附侧视截图与静止片段时间段，注明绝对偏差是否验证。

异常场景

↳

轮廓膨胀与异位鬼影分别记录，先确认异常位置没有实物。

02 / 选择场景

用什么测

反光交通牌、车辆车牌、带反光条的锥桶。优先选择背景空旷、能确认异常位置没有实物的场景。

复核要点

确认不是牌杆、背景物体或其他回波。对比厂家滤波／回波模式时单独录制并记录设置，不能把不同处理后的结果直接混比。

03 / 录包与回放

现场怎么做

  1. 先录不含强反目标的背景，拍摄现场照片；随后对着目标连续录包，缓慢靠近或远离。
  2. 小幅改变方位，让目标经过视场中央和两侧，关键位置短暂停留，记录点云中的目标距离与方位。
  3. 回放对照真实目标的边界，检查轮廓外膨胀及其他位置的成团假点，记录它们在连续帧中的存在情况。
  4. 可移动目标时，将其移出视场再录背景；固定标牌则改变观察方向，检查异常是否随强反目标的出现而变化。
04 / 观察与判定

什么结果才有依据

分别记录「轮廓膨胀」与「异位鬼影」，不把二者混为一项。成团假点必须有现场无实物的证据；单帧出现且不能复核时记作待复核。

05 / 保留证据

报告里体现什么

强反物种类、距离和方位、膨胀／鬼影位置与范围、偶发或持续、移出视场后的变化；附现场照片、基准与异常截图、相对时间段。

异常场景

拖尾

前景到背景之间，本应是空的

检查静止时的空隙
FIG. 04 / LIDAR LAB定性原理演示
激光光斑扫过物体边缘时，可能同时覆盖近处前景与远处背景，混合回波被解算到两者之间，形成本应为空的「拉丝点」或粘连点。这种边缘现象应与运动畸变及跨帧累积拖影区分。
边缘混合回波 → 空隙中的桥接点拖动旋转 · 方向键微调
有效表面点异常点／光路场景参考
01 / 理解原理

激光光斑扫过物体边缘时，可能同时覆盖近处前景与远处背景，混合回波被解算到两者之间，形成本应为空的「拉丝点」或粘连点。这种边缘现象应与运动畸变及跨帧累积拖影区分。

↳

先检查静止单帧，再判断硬件边缘拖尾。

02 / 选择场景

用什么测

柱子、灯杆、锥桶或木板边缘，后方选墙面，前后留几米间距。确认两者之间无枝叶、栏杆等实物。

复核要点

若仅运动或累积显示时出现，优先检查运动补偿、时间同步和显示累积，不直接归因于硬件拖尾。

03 / 录包与回放

现场怎么做

  1. 拍照记录前景、背景和空隙，连续录包，缓慢靠近或远离，并小幅改变观察方向。
  2. 中途停稳，固定设备与目标，保留静止片段；距离由前景和背景各自的点云读取。
  3. 使用单帧侧视或俯视图检查边缘到背景之间的桥接点，逐帧确认静止状态下是否仍存在。
  4. 改变前后景间距或让边缘离开原光束方向，观察拉丝位置和长度是否随几何关系变化。
04 / 观察与判定

什么结果才有依据

静止单帧中仍有位于空隙的点，才支持边缘混合回波的判断。报告区分零散假点与连续粘连；长度沿前后景方向读取，不以截图像素代替实际尺度。

05 / 保留证据

报告里体现什么

前景／背景、各自距离与间距、拖尾位置与长度、零散或连续、静止是否存在、变换几何后的结果；附照片、静止单帧截图与时间段。

玻璃

玻璃会透射和反射激光，玻璃表面可能不出点而后方物体仍可见；反射后的多路径还可能产生异位回波。透射与反射比例取决于玻璃类型、波长及入射角，不能概括成固定角度必然可见或不可见。

↳

分别检查玻璃表面、后方目标与疑似镜像。

02 / 选择场景

用什么测

玻璃门、落地窗、玻璃围挡。记录是否贴膜、镀膜或多层；优先选择后方有清晰物体的位置，也可放置锥桶。

复核要点

排除玻璃上的贴纸、污渍、门框与窗框。疑似镜像需结合现场几何及角度变化判断；没有证据时写「疑似」并保留片段。

03 / 录包与回放

现场怎么做

  1. 拍照确认玻璃、门框及后方目标的位置；连续录包，缓慢靠近或远离，再从正对变为斜向观察。
  2. 分别检查玻璃平面附近、后方目标和其他空间区域的点，固定回波模式和显示设置。
  3. 门框、窗框和后方目标的点不计入玻璃表面。观察不同距离／方向下表面点是否连续。
  4. 可移动后方目标时改变其位置，检查可见点或疑似镜像是否随之移动，并用现场情况复核。
04 / 观察与判定

什么结果才有依据

分别记录玻璃表面出点、后方目标可见与反射鬼影；三者可以同时存在。看到后方目标不等于玻璃障碍物被可靠检测。

05 / 保留证据

报告里体现什么

玻璃类型、距离／方向、表面点连续性、后方目标可见情况、鬼影位置及复核结果；附现场照片、不同角度截图和时间段。

01 / 理解原理

水膜与水面可能改变反射方向，使地面回波变弱或缺失；反射路径也可能产生不对应实物的点，包括地面下方伪点。不同路面、入射角和水层状态的表现不一定相同。

↳

匹配距离与入射角，地面下方伪点需先排除姿态错误。

02 / 选择场景

用什么测

雨后停车场、厂区水泥地、沥青浅水洼。尽量选择同种路面上相邻的干燥、湿润和积水区域，记录湿区范围。

复核要点

先检查地面拟合、安装俯仰角与坐标变换；地面下方的点也可能来自外参或姿态错误。窗口被雨水打湿时单独记录，避免混入窗口污染影响。

03 / 录包与回放

现场怎么做

  1. 保持实际安装高度和姿态，先录干燥基准，再缓慢靠近或经过湿区，关键位置停稳。
  2. 拍照记录路面材质、干／湿／积水边界和周边车辆、柱子等物体。
  3. 回放使用同尺度俯视与侧视图，比较相近距离、相近入射角处的地面点，检查减少、断裂与地面下方异常点。
  4. 对照周围物体，检查异常是否位于无实物位置；条件允许时在路面干燥后复采同一位置。
04 / 观察与判定

什么结果才有依据

地面缺点与反射伪点分别记录。仅比较湿区和远处干区不足以归因于积水，应尽量控制距离与入射角。

05 / 保留证据

报告里体现什么

材质、干湿状态、观察距离／方向、缺点位置与范围、伪点及复采结果；附干湿对照截图、现场照片和时间段。

01 / 理解原理

水滴对激光的散射可能产生空气回波，同时削弱后方目标的回波，使目标点云变稀或消失。自然雾和局部喷雾的粒径与空间分布不同，不能把喷雾档位直接换算成气象能见度。

↳

空气水雾与窗口水滴分开记录，喷雾程度不换算成能见度。

02 / 选择场景

用什么测

自然晨雾、园林喷雾或可控水雾。用车辆或锥桶作固定目标，自然雾与喷雾分别记录；无能见度仪器时仅描述现场现象。

复核要点

记录回波模式和厂家雨雾滤波／标签设置。局部水柱、喷嘴等实物不算空气噪点；过滤后的干净点云也不代表目标回波未受影响。

03 / 录包与回放

现场怎么做

  1. 自然雾中缓慢靠近或远离目标，记录距离与现场照片；若有能见度测量，记录仪器、位置和时间。
  2. 喷雾测试固定设备与目标，连续录下开启前、开启后和消散过程，尽量保持窗口干燥。
  3. 回放在固定目标 ROI 中检查点数和轮廓连续性，同时看空气中新增的噪点或成团回波。
  4. 记录窗口是否湿润；若湿润，另录清洁／干燥窗口后的片段，再判断空气水雾和窗口水滴各自的影响。
04 / 观察与判定

什么结果才有依据

分别描述目标点损失与空气假点。可报告同 ROI、同帧口径的点数变化，但没有受控浓度或能见度时不作天气等级排名。

05 / 保留证据

报告里体现什么

自然雾／喷雾、目标距离、可用的环境记录、目标点变化与连续性、空气噪点范围、窗口湿润情况及恢复过程；附同 ROI 对照截图、照片和时间段。

01 / 理解原理

窗口上的水滴、泥点或浮尘可能遮挡、衰减或散射发射与接收光路，产生局部缺点、目标变稀或近场异常点。影响区域与污染位置、设备光路有关，不能假设每个污点都对应固定形状的盲区。

↳

点云变化、诊断告警与清洁恢复是三份独立证据。

02 / 选择场景

用什么测

水滴、可清除的泥水飞溅与浮尘。按厂家允许的方法处理与清洁，保留污染位置和程度的照片；不使用可能刮伤或损坏镀膜的材料。

复核要点

清洁后仍不恢复时，检查残留水膜、设备状态与数据链路，再次采集；不把未恢复现象简单解释为可逆遮挡。

03 / 录包与回放

现场怎么做

  1. 固定设备和车辆／锥桶，先确认窗口清洁，录制基准并拍摄窗口照片。
  2. 连续记录「干净 → 少量脏污 → 脏污增加 → 按厂家方法清洁后」，每个阶段停留并留照片与时间标记。
  3. 在相同 ROI 和回放设置下比较目标轮廓、缺点方向、近场异常点，观察清洁后是否恢复。
  4. 同时保存可用的脏污／遮挡诊断告警；无告警与点云正常分开记录。没有诊断能力时标注「不支持」或「未采集」。
04 / 观察与判定

什么结果才有依据

用同位置的干净与污染片段对照，并以清洁后的恢复验证关联。污染照片用于描述状态，未测量的面积比例不写成精确覆盖率。

05 / 保留证据

报告里体现什么

脏污种类、位置、程度、目标变化与缺点区域、告警及触发时刻、清洁后恢复情况；附四阶段点云对照、窗口照片和时间段。
