01

基础性能

有效检测距离

目标能看多远

FIG. 01 / PRINCIPLE原理示意
随距离增加，目标点云可能变稀或消失。有效检测距离以点云中仍能分辨出目标轮廓的最远距离为准。
真实表面／有效回波光束／异常回波
01 / 理解原理

随距离增加，目标点云可能变稀或消失。有效检测距离以点云中仍能分辨出目标轮廓的最远距离为准。

↳

距离增大，轮廓会变稀。实测以还能分辨出目标轮廓的距离为准。

02 / 选择场景

用什么测

人、车、骑行者、锥桶，只看正面。

03 / 录包与回放

现场怎么做

  1. 连续录包，逐步改变目标与 LiDAR 的距离，保持目标正面朝向雷达。
  2. 回放点云，找出各类目标最远可分辨的距离，按 5m 档位记录。
  3. 判定时看是否能分辨出目标轮廓；仅有几个孤立点，不能算目标可分辨。
04 / 保留证据

报告里体现什么

四类目标的有效检测距离、临界距离的点云截图和包内时间点。

02

基础性能

测距精度

从侧面看平面厚度

FIG. 02 / PRINCIPLE原理示意
测距随机误差及通道差异会使平面点云呈现一定厚度。本项以「不存在整体偏移」为前提，用点云厚度评价测距精度，并观察随距离增加的变化；距离直接从点云读取，无需另做实物距离测量。
真实表面／有效回波光束／异常回波
01 / 理解原理

测距随机误差及通道差异会使平面点云呈现一定厚度。本项以「不存在整体偏移」为前提，用点云厚度评价测距精度，并观察随距离增加的变化；距离直接从点云读取，无需另做实物距离测量。

↳

比较墙面厚度与墙角形态，同时看点云是否变稀。本项以不存在整体偏移为前提。

02 / 选择场景

用什么测

平整墙面和清晰墙角。

03 / 录包与回放

现场怎么做

  1. 保持安装姿态，连续靠近或远离墙面、墙角并录包。
  2. 回放时从点云读取距离，分别查看 10、20、30m……附近的片段，保持累积时间、点大小一致。
  3. 切到侧视图读取墙面厚度；墙角分别看两面墙的厚度，以及拐角是否清晰、有无分层或粘连。
  4. 同时观察点云是否明显变稀、缺点。
04 / 保留证据

报告里体现什么

按每 10m 一行，记录距离、墙面厚度、墙角表现、稀疏／缺点情况、截图及包内时间点，体现厚度随距离增加的变化。

03

异常场景

强反鬼影

强回波之外的假目标

FIG. 03 / PRINCIPLE原理示意
强反物返回的激光信号很强，可能引起接收饱和、杂散光或串扰，使回波被错误解算，在真实物体之外形成「鬼影」；也可能让物体轮廓向外膨胀。
真实表面／有效回波光束／异常回波
01 / 理解原理

强反物返回的激光信号很强，可能引起接收饱和、杂散光或串扰，使回波被错误解算，在真实物体之外形成「鬼影」；也可能让物体轮廓向外膨胀。

↳

重点检查真实物体之外的成团假点，以及轮廓向外膨胀的现象。

02 / 选择场景

用什么测

反光交通牌、车辆车牌、带反光条的锥桶。尽量选择背景空旷的位置，方便判断哪些点不对应真实物体。

03 / 录包与回放

现场怎么做

  1. 对着目标连续录包，缓慢靠近或远离，再小幅左右转动，让目标经过视场中央和两侧。
  2. 回放检查目标之外有没有成团假点、轮廓是否明显变大，以及这些异常是否随目标移动或离开视场而变化。
  3. 拍一张现场照片用于对照。
04 / 保留证据

报告里体现什么

测试物体、有无鬼影／膨胀、出现时的距离和方位、异常是零星还是成团、是否持续出现；附现场照片、点云截图和包内时间点。

04

异常场景

拖尾

边缘与背景之间的拉丝

FIG. 04 / PRINCIPLE原理示意
激光光斑有一定宽度，扫到物体边缘时，可能同时照到近处物体和远处背景。混合回波被错误解算后，两者之间本应为空的位置会出现「拉丝点」或粘连点。
真实表面／有效回波光束／异常回波
01 / 理解原理

激光光斑有一定宽度，扫到物体边缘时，可能同时照到近处物体和远处背景。混合回波被错误解算后，两者之间本应为空的位置会出现「拉丝点」或粘连点。

↳

前景和背景之间本应为空。静止片段仍有粘连点，才有助于判断边缘拖尾。

02 / 选择场景

用什么测

柱子、灯杆、锥桶或木板边缘，后方选墙面作为背景，前后留几米间距。

03 / 录包与回放

现场怎么做

  1. 连续录包，缓慢靠近或远离，并小幅改变观察方向；中途短暂停留，保留静止片段。
  2. 回放看物体边缘到背景之间有没有拉丝、桥接点，以及静止时是否仍存在。
  3. 拍一张现场照片用于对照。
04 / 保留证据

报告里体现什么

前景／背景物体、出现拖尾时的距离、拖尾位置和大致长度、是零散点还是连续粘连、静止时是否存在；附现场照片、点云截图和包内时间点。

05

异常场景

玻璃

看见后方，未必看见玻璃

FIG. 05 / PRINCIPLE原理示意
玻璃既透光又反射。激光可能穿过玻璃打到后方物体，也可能反射到其他方向，造成玻璃自身缺点；反射光路还可能形成虚假目标。
真实表面／有效回波光束／异常回波
01 / 理解原理

玻璃既透光又反射。激光可能穿过玻璃打到后方物体，也可能反射到其他方向，造成玻璃自身缺点；反射光路还可能形成虚假目标。

↳

门框和玻璃后方的点，不算玻璃本身被检测到。

02 / 选择场景

用什么测

玻璃门、落地窗、玻璃围挡。优先选后方有明显物体的位置，也可以在玻璃后放一个锥桶。

03 / 录包与回放

现场怎么做

  1. 连续录包，缓慢靠近或远离，并从正对变为稍斜着观察。
  2. 回放分别看玻璃表面有没有点、后方物体是否可见、其他位置有没有鬼影。
  3. 门框和玻璃后的点，不算玻璃本身被检测到。
  4. 拍一张现场照片用于对照。
04 / 保留证据

报告里体现什么

玻璃类型、观察距离和方向、玻璃表面出点情况、后方物体可见情况、有无鬼影及其位置；附现场照片、点云截图和包内时间点。

06

异常场景

潮湿地面与积水

水膜改变反射方向

FIG. 06 / PRINCIPLE原理示意
水膜和水面可能增强镜面反射，使激光偏离接收方向，造成地面缺点；反射光路也可能把周围物体成像到错误位置，出现鬼影。
真实表面／有效回波光束／异常回波
01 / 理解原理

水膜和水面可能增强镜面反射，使激光偏离接收方向，造成地面缺点；反射光路也可能把周围物体成像到错误位置，出现鬼影。

↳

对照同种路面的干湿区域，观察地面缺点与不对应实物的异常点。

02 / 选择场景

用什么测

雨后停车场、厂区水泥地、沥青路面的浅水洼。尽量选择同种路面上相邻的干燥、湿润和积水区域，方便对照。

03 / 录包与回放

现场怎么做

  1. 保持实际安装高度，缓慢靠近或经过这些区域，连续录包。
  2. 回放比较干湿区域的地面点是否减少、断裂，以及有无鬼影或地面下方的异常点。
  3. 对照附近车辆、柱子等实物，确认异常点是否对应真实物体。
  4. 拍照记录湿区和积水范围。
04 / 保留证据

报告里体现什么

路面材质、干／湿／积水状态、观察距离、缺点位置和范围、有无鬼影及其位置；附干湿对比点云截图、现场照片和包内时间点。

07

异常场景

雾与喷雾

目标变弱，空气产生回波

FIG. 07 / PRINCIPLE原理示意
雾和喷雾中的小水滴会散射激光，可能在空气中形成噪点，同时削弱后方目标的回波，造成目标点云变稀或消失。
真实表面／有效回波光束／异常回波
01 / 理解原理

雾和喷雾中的小水滴会散射激光，可能在空气中形成噪点，同时削弱后方目标的回波，造成目标点云变稀或消失。

↳

同时看真实目标损失了多少点、空气中增加了哪些点，并记录窗口是否被淋湿。

02 / 选择场景

用什么测

自然晨雾、洒水车水雾、园林喷雾。选车辆或锥桶作为观察目标，自然雾与喷雾分别记录。

03 / 录包与回放

现场怎么做

  1. 自然雾中缓慢靠近或远离目标，连续录包。
  2. 喷雾测试保持目标不动，连续录下喷雾开启前、开启后和消散过程。
  3. 回放看目标是否丢点、空气中是否出现雾状点或成团假目标，同时记录雷达窗口是否被淋湿。
04 / 保留证据

报告里体现什么

雾／喷雾场景、目标及距离、目标点云变化、噪点位置和范围、窗口是否湿润；附现场照片、对比点云截图和包内时间点。

08

异常场景

雷达窗口脏污

窗口污染影响整条光路

FIG. 08 / PRINCIPLE原理示意
窗口脏污会遮挡或削弱激光的发射、接收，也可能产生散射。表现为部分方向缺点、目标点云变稀，或窗口附近出现异常点。
真实表面／有效回波光束／异常回波
01 / 理解原理

窗口脏污会遮挡或削弱激光的发射、接收，也可能产生散射。表现为部分方向缺点、目标点云变稀，或窗口附近出现异常点。

↳

观察污染位置对应的缺点区域，并在清洁后检查是否恢复。

02 / 选择场景

用什么测

水滴、泥水飞溅形成的泥点、浮尘。选择能按厂家方法清除的脏污，拍照记录污染位置和程度。

03 / 录包与回放

现场怎么做

  1. 固定雷达和前方车辆或锥桶，连续录下「窗口干净 → 少量脏污 → 脏污增加 → 清洁后」的过程。
  2. 回放比较目标是否变稀或消失、哪些方向缺点、有无异常点，以及清洁后是否恢复。
  3. 设备有脏污告警的话，顺便记录是否触发。
04 / 保留证据

报告里体现什么

脏污种类、位置和程度、目标点云变化、缺点／异常点区域、清洁后恢复情况及告警情况；附窗口照片、对比点云截图和包内时间点。
