细节分辨记录「连续可分辨／间歇可分辨／不可分辨」；几何、噪声、恢复时间、同步与丢帧保留实际统计值。项目阈值必须在测试前定义，包括 ROI、帧数、统计方法及允许误差，不能事后挑选好看的单帧代替连续结果。

临界或异常工况至少复采一次。设备、镜头、ISP 或处理模式改变后重新建立基准。本文的采集档位与复核流程是项目约定，不代表行业统一标准。

01 / 理解原理

镜头投影、径向／切向畸变和输出裁切共同决定可用视场与像素几何。广角中的直线弯曲可以是正常投影特性；需要检查的是实际覆盖、标定模型及处理后几何是否满足应用要求。

↳

原始投影、去畸变输出与有效视场分别留证。

02 / 选择场景

用什么测

尺寸已知的棋盘格／标定板、直墙与地面标线，覆盖画面中央、四角和边缘。鱼眼镜头使用与投影类型相符的标定模型。

复核要点

排除标定板翘曲、角点误检、保护窗折射、安装遮挡和错误缩放内参。正常镜头畸变与错误去畸变分开记录。

03 / 录包与回放

现场怎么做

  1. 使用实际安装姿态与输出模式，记录近场遮挡及裁切；移动目标到视场边界，记录独立测得的距离、横向位置与方位。
  2. 让平整标定板以不同距离、位置和姿态覆盖全画面，保持可读且无运动模糊；保留标定与独立验证两组图像。
  3. 分别回放原始图与去畸变图；检查边缘弯曲、裁切、黑边及坐标映射，不把去畸变后的黑边计入有效视场。
  4. 有标定工具时，在未参与拟合的图像上报告分区域重投影残差、有效角点数及模型／参数；改变分辨率或裁切后复验。
04 / 观察与判定

什么结果才有依据

按中央、四角与边缘给出覆盖和几何残差。小的训练图重投影误差不能单独证明实际视场、外参或远处投影准确；角度数值需已知几何或合适投影模型支持。

05 / 保留证据

报告里体现什么

原始／有效视场、遮挡区域、输出裁切、投影模型、标定与验证集、分区域残差及配置变更后的结果；附原始与处理图、参数文件、帧号和时间段。

↳

明确要分辨的细节，再记录距离、位置和像素尺寸。

02 / 选择场景

用什么测

人、车、骑行者、锥桶，以及尺寸已知的黑白条纹板／文字板；固定目标外观，分别检查中央与四角。精确 MTF 需另做受控图卡测试。

复核要点

先排除图像缩放、JPEG 压缩、运动、离焦和自动曝光变化。边缘低于中央时，结合镜头场曲、安装倾斜与标定情况复核。

03 / 录包与回放

现场怎么做

  1. 固定设备，先在充足且稳定光照下拍静止目标，检查镜头清洁、对焦和景深；保存曝光与增益。
  2. 从近到远分档停留，距离用独立测距或场地标记记录；同一目标依次放在中央及边缘位置，保持尺寸、朝向一致。
  3. 按原始尺寸回放，每档记录目标像素高度／宽度、轮廓和预先指定细节是否可分辨，观察混叠、伪纹理、锐化光晕。
  4. 临界位置重复靠近／远离并复采；有自动对焦时记录锁定、搜索及重新对焦过程，固定焦相机注明工作距离范围。
04 / 观察与判定

什么结果才有依据

按目标、位置和距离记录连续／间歇／不可分辨及对应像素尺寸。明确「分辨的细节」是什么；不能直接命名为算法检测距离，也不能从普通现场截图计算 MTF。

05 / 保留证据

报告里体现什么

各目标尺寸／距离／画面位置、像素尺寸、指定细节、临界档位、对焦状态与复测；附原尺寸 ROI、整帧、帧号与时间段。

光子减少会降低图像信噪比；增加增益或曝光能改变亮度，却可能引入噪声、运动模糊或帧率变化。时域降噪可以让静止背景平滑，同时抹掉弱纹理或使运动目标产生残影。

↳

固定曝光用于隔离变量，实际 AE 模式用于检查部署表现。

02 / 选择场景

用什么测

黄昏、暗停车场或可调光室内；使用灰色均匀区域、暗色衣着行人、条纹板和缓慢移动目标。静止与运动片段分别采集。

复核要点

排除光源闪烁、压缩、热状态与显示提亮影响。时间噪声统计要求静止目标、稳定照明和固定曝光／增益，自动变化片段不能直接套用。

03 / 录包与回放

现场怎么做

  1. 先录充足光照基准，固定构图和目标，再逐步降低照明或在不同自然光阶段复采；测得照度时记录仪器与目标处测量条件。
  2. 一组固定曝光／增益观察变化，另一组使用实际 AE／降噪配置；同步保留逐帧曝光、增益和帧间隔。
  3. 在原始尺寸 ROI 中检查亮度、颜色、弱纹理和坏点／条带；固定均匀区域的连续帧可统计逐像素时间标准差，再汇总 ROI 分布。
  4. 在相同光照下让目标移动并停下，观察细节损失、拖影和 AE 触及曝光上限后的变化；恢复照明后复采。
04 / 观察与判定

什么结果才有依据

亮度、噪声、细节、运动拖影及实际帧率分别记录。ISP 后图像的噪声统计只反映该处理链路，不能当作传感器读出噪声或 EMVA 1288 SNR。

05 / 保留证据

报告里体现什么

照明条件、曝光／增益、ROI 与帧数、噪声口径、暗部细节、运动拖影和实际帧率；附亮／暗及静止／运动对照与配置元数据。

↳

静止 HDR 效果、运动伪影和 AE／AWB 恢复分别记录。

02 / 选择场景

用什么测

有明亮出口的暗车库／通道、窗口逆光、侧方强光；在亮暗区域分别放置有纹理目标，并加入移动行人或车辆。强光造成的眩光与 HDR 曝光问题分别观察。

复核要点

排除保护窗反射、镜头脏污、光源位置变化与播放器色调映射。HDR 开关可能联动帧率、曝光和 LFM，所有联动配置一起记录。

03 / 录包与回放

现场怎么做

  1. 先固定构图，同时保留亮区、暗区和静止纹理目标；记录光源方向及 HDR／AE／AWB 设置，支持模式切换时同工况分别录制。
  2. 加入移动目标，逐帧检查双边缘、重影和局部颜色／亮度异常，不只挑选静止帧。
  3. 连续记录由暗到亮、由亮到暗的过程；使用同一 ROI 跟踪目标细节、亮度及可用的曝光／增益／白平衡元数据。
  4. 预先定义稳定判据，例如 ROI 亮度与指定细节连续若干帧进入允许范围；报告首次进入并持续满足的帧号、耗时和失败片段。
04 / 观察与判定

什么结果才有依据

分别记录高光／暗部细节、眩光、运动伪影和曝光／白平衡恢复时间。没有已知亮度比及标准测量条件时，不从截图推算动态范围 dB；白平衡稳定不等于色彩精度达标。

05 / 保留证据

报告里体现什么

亮暗场景、HDR／AE／AWB 模式、亮暗 ROI 细节、眩光／运动伪影、收敛判据与双向恢复时间；附逐帧曲线或帧序列、元数据与时间段。

01 / 理解原理

LED 的脉冲发光与曝光窗口可能错位，产生亮度波动、条带或「灯亮但图像中暗掉」。LFM、HDR、曝光时间、光源频率／占空比及采样相位共同影响结果。

↳

更改曝光或采样相位复测，一种灯具的结果不能外推到所有 LED。

02 / 选择场景

用什么测

可控制且可验证亮灭状态的 LED 信号灯／灯板、车辆尾灯或电子标牌；手机屏幕只能作为辅助案例，不能代替交通灯验证。

复核要点

排除灯具真实切换、遮挡、自动曝光、过曝、压缩与滚动读出条带。一般抗 50／60Hz 频闪设置不等同于交通 LED 的 LFM。

03 / 录包与回放

现场怎么做

  1. 记录光源类型和实际点亮状态；受控光源记录频率／占空比及参考信号，未知参数明确标注，不从肉眼稳定推断恒定发光。
  2. 固定目标距离与视角，在实际帧率／HDR／LFM 配置下连续录制；有条件时分别改变曝光时间、光源参数或触发相位，覆盖不同组合。
  3. 按帧号在灯面 ROI 统计亮度及暗帧比例／最长连续暗帧，并检查条带、颜色变化与局部饱和；阈值由同场景点亮／熄灭对照预先定义。
  4. 复采并改变采样相位或采用不同帧率，避免一次恰好相位锁定掩盖问题；同时确认邻近运动目标没有因长曝光而失去细节。
04 / 观察与判定

什么结果才有依据

有独立点亮参考时才能判断误暗／误闪烁。稳定拍到一种灯具不代表兼容所有 LED；灯面很小时先排除像素不足，记录丢失的是亮度、颜色还是显示内容。

05 / 保留证据

报告里体现什么

光源与参考、已知频率／占空比、曝光／帧率／HDR／LFM 组合、暗帧比例／最长暗段、条带与颜色、相位复测结果；附整帧和灯面帧序列。

02 / 选择场景

用什么测

固定相机拍摄横向移动的带清晰边缘目标，或在封闭场地用移动平台观察标线／立柱；设置静止基准，记录距离与可测运动速度。

复核要点

排除离焦、支架振动、Rolling Shutter、跨帧显示累积和压缩。速度未知时不从画面反推高精度物理速度。

03 / 录包与回放

现场怎么做

  1. 在稳定充足照明下固定对焦，先录静止目标；再以可重复速度横向运动，保留经过相同 ROI 的片段。
  2. 手动模式下分档改变曝光，记录增益及实际帧率；无法手动设置时按逐帧元数据分组，不把 AE 联动视为单变量实验。
  3. 原尺寸逐帧检查运动方向边缘宽度、纹理和停下后的残影；比较短曝光／长曝光与静止／运动片段。
  4. 支持时域降噪开关时同工况分别录制，并检查停下后历史轮廓的消退；没有开关时只能描述现象并标为疑似成因。
04 / 观察与判定

什么结果才有依据

报告模糊长度的测量口径、像素值与配置，区分曝光积分模糊、跨帧残影及几何倾斜。降低帧率本身不必然产生更长模糊，关键是实际曝光和图像运动。

05 / 保留证据

报告里体现什么

目标距离／运动方式／速度来源、曝光／增益／帧率、模糊像素长度与时域残影、短曝光对照；附静止和运动 ROI、帧序列及元数据。

逐行曝光使画面各行对应不同时间，运动目标或相机转动可能使直线倾斜、弯曲或呈波纹。每行曝光时长与整帧行间时间跨度是不同参数；短曝光能减轻模糊，但不一定消除行间几何畸变。

↳

短曝光可以减轻模糊，行间几何畸变仍取决于读出时序与运动。

02 / 选择场景

用什么测

横向移动的竖直杆／条纹板、缓慢往返转动相机观察直立柱；实际支架上另录有代表性的振动片段，保持照明稳定。

复核要点

排除正常镜头畸变、去畸变／电子防抖处理、镜头或支架松动及运动模糊。不能把行间时间跨度直接当成每行曝光时间。

03 / 录包与回放

现场怎么做

  1. 记录快门类型、读出方向与厂家提供的行时间／帧读出信息；先录静止直线，建立镜头畸变基准。
  2. 使用较短曝光让边缘保持清晰，按可重复运动方式分别向两个方向移动或转动，检查倾斜是否随运动方向反转。
  3. 在相同输出模式下改变运动速度，再检查实际安装振动；模式变化时重新记录分辨率、ROI、帧率与读出参数。
  4. 有独立运动真值及行时序时，可按投影模型复核；缺少真值时只描述像素位移／倾斜，不从一次倾斜精确推算读出时间。
04 / 观察与判定

什么结果才有依据

静止与双向运动对照支持对行间畸变的判断；Global Shutter 设备也应检查振动和曝光模糊，但不将它们标为 Rolling Shutter。波纹与直线倾斜分别记录。

05 / 保留证据

报告里体现什么

快门／读出参数、运动方向和速度来源、静止与双向运动对照、倾斜／波纹位置及模式差异；附原图、ROI 和相应元数据。

01 / 理解原理

曝光、读出、传输和主机接收是不同事件。时钟同步不保证曝光同时；接收时刻受缓冲和负载影响，不能替代曝光时刻。丢帧、重复帧和时序抖动会影响跨相机及相机与 LiDAR／IMU 的融合。

↳

PTP 锁定不等于曝光同步；未配对帧也必须进入统计。

02 / 选择场景

用什么测

实际多相机／传感器配置、可记录的触发参考和各相机共同可见的受控光脉冲；负载测试使用实际分辨率、帧率、编码与录包路径。跨模态事件需被两种传感器观测或具有共同硬件时间参考。

复核要点

Rolling Shutter 不同行的曝光时间仍不同；HDR 可能有多个曝光事件。未采集触发或曝光参考时，不能把图像包时间戳一致写成硬件同步达标，也不能直接用异时钟域时间相减。

03 / 录包与回放

现场怎么做

  1. 核对厂家时间戳定义、单位、时钟域、曝光起点／中点／终点及 HDR／逐行语义；保存同步锁定状态、触发日志、帧号和主机单调时钟接收时刻。
  2. 在空闲与部署负载下各连续采集预定时长，明确起止边界；按帧号及曝光时间检查缺号、重复、乱序、帧间隔和长期漂移，说明帧号回绕处理。
  3. 多相机用共同硬件触发及可见事件对照实际曝光；报告按触发 ID 或明确定义规则配对的时间差分布，同时保留未配对帧，不能只按最近时间戳配对后忽略缺帧。
  4. 延迟测试先建立设备与主机时钟的映射及误差，再从定义明确的曝光事件量到指定接收／算法输入事件；没有共同时间基准时只报告同一时钟域可测的延迟分段。
  5. 复测启动、同步重锁和长时间运行，区分设备未产帧、传输失败、驱动丢弃及录包丢失；缺少链路日志时原因标为待复核。
04 / 观察与判定

什么结果才有依据

分别给出产出／接收／录入帧数、有效帧率、缺帧／重复、帧间隔、曝光同步误差与延迟。报告 P50／P95／最大值、样本数和时钟映射误差；PTP 锁定或平均帧率正常不能单独证明曝光同步与帧完整。

05 / 保留证据

报告里体现什么

时间戳语义／单位／时钟域、同步与配对方式、采集时长／负载、帧数与缺失定位、时间差／间隔／延迟分布、重锁及漂移；附日志、统计脚本版本与异常帧索引。

01 / 理解原理

空气中的雾和雨会衰减、散射光线，降低远处对比度；湿路面反射和强光可能改变曝光。保护窗上的水滴属于另一条影响路径，需与空气天气分开观察。

↳

自然天气差异需要如实保留，局部喷雾不能换算气象能见度。

02 / 选择场景

用什么测

自然雾、雨后路面、可控水雾中的固定车辆／条纹目标；空气影响测试尽量维持镜头／保护窗干燥，湿路面另设干燥对照。

复核要点

排除水滴、结露、AE 改变、目标运动与距离差异。没有能见度测量时明确标为目视天气记录。

03 / 录包与回放

现场怎么做

  1. 先在清晰空气中记录同位置基准，再采集雨雾条件，保存目标距离、光照、天气与窗口状态；自然天气不能匹配时保留差异。
  2. 固定目标与构图，逐帧检查轮廓和纹理对比；有受控条件时使用固定曝光／增益，并另录实际自动模式。
  3. 湿地面场景检查反射、眩光和 AE 对邻近目标的影响；记录光源方向与实际安装保护窗。
  4. 窗口湿润后拍照并清洁／干燥复采，单独比较窗口水滴影响；喷雾只记录局部工况，不换算气象能见度。
04 / 观察与判定

什么结果才有依据

分别记录空气散射、湿路面反射、目标细节损失及窗口状态。没有受控天气和光照真值时不做精确天气等级排名，也不把后处理增强后的亮度当成真实细节恢复。

05 / 保留证据

报告里体现什么

天气／光照／目标距离、窗口与路面状态、对比度／细节观察、AE 变化与清洁后对照；附现场照片、同 ROI 帧序列与时间段。

01 / 理解原理

水滴、泥点、油膜和结露可能引起遮挡、模糊、散射与眩光。靠近镜头的污物常呈离焦影响，不必然在图像中形成同形状的清晰遮挡；逆光下影响也可能加重。

↳

图像退化、诊断告警与清洁恢复是三份独立证据。

02 / 选择场景

用什么测

可清除水滴、浮尘与泥水飞溅；镜头、外部保护窗和挡风玻璃分别记录。结露只观察允许工况或自然过程，按厂家方法处理与清洁。

复核要点

区分外表面污染、保护窗内部结露、挡风玻璃污物和镜头离焦。清洁动作与允许材料遵循厂家要求，不能把加热功能开启等同于已除雾。

03 / 录包与回放

现场怎么做

  1. 固定设备和目标，先录清洁基准并拍摄光学表面；保留原始图、部署图像与诊断状态。
  2. 连续记录「清洁 → 少量污染 → 污染增加 → 清洁／除雾恢复」，每阶段记录表面照片和时间标记，不用照片估计精确覆盖率。
  3. 在同 ROI 检查细节、对比度、局部遮挡、眩光及 AE 变化；污染工况分别采集顺光与逆光对照。
  4. 保存遮挡／脏污／除雾等可用诊断告警及触发时间；清洁后复采相同工况，未恢复时复核残留油膜、水汽与设备状态。
04 / 观察与判定

什么结果才有依据

图像退化、诊断告警与恢复是独立结果，无告警不能当作画面正常。局部污物可能影响大范围画面，不能用一个污点的位置直接指定固定盲区。

05 / 保留证据

报告里体现什么

污染位置／类型／程度、顺逆光条件、受影响 ROI、细节与对比变化、诊断／除雾触发及恢复；附四阶段图像、表面照片与时间段。
