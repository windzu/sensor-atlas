# LiDAR 硬件评测标准

采用常见目标与现场场景，通过连续录包、回放检查评测 LiDAR 硬件的点云质量。报告记录观察结果，并保留相应截图和包内时间点，便于复核。

## 1. 有效检测距离

**基本原理**：随距离增加，目标点云可能变稀或消失。有效检测距离以点云中仍能分辨出目标轮廓的最远距离为准。

**测试目标**：人、车、骑行者、锥桶，只看正面。

**录包回放**：

- 连续录包，逐步改变目标与 LiDAR 的距离，保持目标正面朝向雷达。
- 回放点云，找出各类目标最远可分辨的距离，按 5m 档位记录。
- 判定时看是否能分辨出目标轮廓；仅有几个孤立点，不能算目标可分辨。

**报告内容**：四类目标的有效检测距离、临界距离的点云截图和包内时间点。

## 2. 测距精度

**基本原理**：测距随机误差及通道差异会使平面点云呈现一定厚度。本项以「不存在整体偏移」为前提，用点云厚度评价测距精度，并观察随距离增加的变化；距离直接从点云读取，无需另做实物距离测量。

**测试场景**：平整墙面和清晰墙角。

**录包回放**：

- 保持安装姿态，连续靠近或远离墙面、墙角并录包。
- 回放时从点云读取距离，分别查看 10、20、30m……附近的片段，保持累积时间、点大小一致。
- 切到侧视图读取墙面厚度；墙角分别看两面墙的厚度，以及拐角是否清晰、有无分层或粘连。
- 同时观察点云是否明显变稀、缺点。

**报告内容**：按每 10m 一行，记录距离、墙面厚度、墙角表现、稀疏／缺点情况、截图及包内时间点，体现厚度随距离增加的变化。

## 3. 强反鬼影

**基本原理**：强反物返回的激光信号很强，可能引起接收饱和、杂散光或串扰，使回波被错误解算，在真实物体之外形成「鬼影」；也可能让物体轮廓向外膨胀。

**测试物体**：反光交通牌、车辆车牌、带反光条的锥桶。尽量选择背景空旷的位置，方便判断哪些点不对应真实物体。

**录包回放**：

- 对着目标连续录包，缓慢靠近或远离，再小幅左右转动，让目标经过视场中央和两侧。
- 回放检查目标之外有没有成团假点、轮廓是否明显变大，以及这些异常是否随目标移动或离开视场而变化。
- 拍一张现场照片用于对照。

**报告内容**：测试物体、有无鬼影／膨胀、出现时的距离和方位、异常是零星还是成团、是否持续出现；附现场照片、点云截图和包内时间点。

## 4. 拖尾

**基本原理**：激光光斑有一定宽度，扫到物体边缘时，可能同时照到近处物体和远处背景。混合回波被错误解算后，两者之间本应为空的位置会出现「拉丝点」或粘连点。

**测试物体**：柱子、灯杆、锥桶或木板边缘，后方选墙面作为背景，前后留几米间距。

**录包回放**：

- 连续录包，缓慢靠近或远离，并小幅改变观察方向；中途短暂停留，保留静止片段。
- 回放看物体边缘到背景之间有没有拉丝、桥接点，以及静止时是否仍存在。
- 拍一张现场照片用于对照。

**报告内容**：前景／背景物体、出现拖尾时的距离、拖尾位置和大致长度、是零散点还是连续粘连、静止时是否存在；附现场照片、点云截图和包内时间点。

## 5. 玻璃

**基本原理**：玻璃既透光又反射。激光可能穿过玻璃打到后方物体，也可能反射到其他方向，造成玻璃自身缺点；反射光路还可能形成虚假目标。

**测试物体**：玻璃门、落地窗、玻璃围挡。优先选后方有明显物体的位置，也可以在玻璃后放一个锥桶。

**录包回放**：

- 连续录包，缓慢靠近或远离，并从正对变为稍斜着观察。
- 回放分别看玻璃表面有没有点、后方物体是否可见、其他位置有没有鬼影。
- 门框和玻璃后的点，不算玻璃本身被检测到。
- 拍一张现场照片用于对照。

**报告内容**：玻璃类型、观察距离和方向、玻璃表面出点情况、后方物体可见情况、有无鬼影及其位置；附现场照片、点云截图和包内时间点。

## 6. 潮湿地面与积水

**基本原理**：水膜和水面可能增强镜面反射，使激光偏离接收方向，造成地面缺点；反射光路也可能把周围物体成像到错误位置，出现鬼影。

**测试场景**：雨后停车场、厂区水泥地、沥青路面的浅水洼。尽量选择同种路面上相邻的干燥、湿润和积水区域，方便对照。

**录包回放**：

- 保持实际安装高度，缓慢靠近或经过这些区域，连续录包。
- 回放比较干湿区域的地面点是否减少、断裂，以及有无鬼影或地面下方的异常点。
- 对照附近车辆、柱子等实物，确认异常点是否对应真实物体。
- 拍照记录湿区和积水范围。

**报告内容**：路面材质、干／湿／积水状态、观察距离、缺点位置和范围、有无鬼影及其位置；附干湿对比点云截图、现场照片和包内时间点。

## 7. 雾与喷雾

**基本原理**：雾和喷雾中的小水滴会散射激光，可能在空气中形成噪点，同时削弱后方目标的回波，造成目标点云变稀或消失。

**测试场景**：自然晨雾、洒水车水雾、园林喷雾。选车辆或锥桶作为观察目标，自然雾与喷雾分别记录。

**录包回放**：

- 自然雾中缓慢靠近或远离目标，连续录包。
- 喷雾测试保持目标不动，连续录下喷雾开启前、开启后和消散过程。
- 回放看目标是否丢点、空气中是否出现雾状点或成团假目标，同时记录雷达窗口是否被淋湿。

**报告内容**：雾／喷雾场景、目标及距离、目标点云变化、噪点位置和范围、窗口是否湿润；附现场照片、对比点云截图和包内时间点。

## 8. 雷达窗口脏污

**基本原理**：窗口脏污会遮挡或削弱激光的发射、接收，也可能产生散射。表现为部分方向缺点、目标点云变稀，或窗口附近出现异常点。

**测试脏污**：水滴、泥水飞溅形成的泥点、浮尘。选择能按厂家方法清除的脏污，拍照记录污染位置和程度。

**录包回放**：

- 固定雷达和前方车辆或锥桶，连续录下「窗口干净 → 少量脏污 → 脏污增加 → 清洁后」的过程。
- 回放比较目标是否变稀或消失、哪些方向缺点、有无异常点，以及清洁后是否恢复。
- 设备有脏污告警的话，顺便记录是否触发。

**报告内容**：脏污种类、位置和程度、目标点云变化、缺点／异常点区域、清洁后恢复情况及告警情况；附窗口照片、对比点云截图和包内时间点。
