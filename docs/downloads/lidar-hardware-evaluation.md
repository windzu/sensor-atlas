# LiDAR 硬件评测标准

采用常见目标与现场场景，通过连续录包、回放检查 LiDAR 硬件的点云质量。保留八项轻量现场测试，以观察、对照和复核为核心。本文是项目内的评测约定，未设定跨型号通用的合格阈值；验收时应事先约定目标、工况与判定要求。

## 评测前准备

先做干净窗口、无遮挡、无明显雨雾的基准采集，再改变距离、角度或单一环境条件。比较不同设备时，使用相同目标、安装高度、测试路线与回放设置；无法一致的配置要在报告中说明。

| 检查项 | 需要记录或确认的内容 |
| --- | --- |
| 设备与配置 | 型号、序列号、固件、驱动版本、帧率、扫描模式、回波模式、厂家滤波设置；无法取得的字段标注「未知」 |
| 安装与视场 | 安装高度、俯仰角、目标方位；先确认近场盲区、视场裁切和安装遮挡 |
| 目标与环境 | 目标尺寸、材质／颜色、朝向、天气、光照、路面；反射率未测量时不填写估计值 |
| 录制数据 | 优先保留原始包与传感器配置，同时保留解析点云；只有点云时说明数据链路与已启用的处理 |
| 时间与完整性 | 包名、传感器时间戳与包内相对时间、点云 topic／坐标系；检查丢帧、丢包及诊断告警 |
| 回放显示 | 固定视角、点大小、着色字段、色标范围、ROI、单帧／累积时长；运动片段不用于厚度或拖尾定量 |

每次采集包含条件变化前后的连续片段，关键距离或异常位置短暂停留，便于逐帧检查。自然条件无法控制时，记录实际情况，不把天气不同的两段结果直接归因于设备差异。

## 判定与复核约定

| 结果 | 使用条件 |
| --- | --- |
| 未观察到异常 | 在已记录工况和检查片段内未出现所查现象，不能外推为所有工况均无异常 |
| 观察到异常 | 异常可在连续片段中复核，已用现场照片或基准排除真实物体；注明偶发／持续及复现条件 |
| 待复核 | 仅单帧异常，或受遮挡、运动、丢包、显示设置影响，原因尚不能确认 |
| 未测试 | 场景未采集或数据不可用，单独标注原因，不记作通过 |

有效检测距离记录「连续可分辨／间歇可分辨／不可分辨」，测距精度记录实际观察或统计值，不强行套用异常项的结论。临界结果至少再次采集同工况片段；复测不一致时保留全部结果与差异。本文的距离档位、复核方法属于项目约定，不代表行业标准。

## 1. 有效检测距离

**基本原理**：固定角分辨率下，距离增大通常使目标上的采样点变少；回波还受目标材质、入射角和环境影响。有效检测距离以点云中仍能连续分辨出目标轮廓的最远距离为准，不能直接等同于算法检出距离或厂家标称量程。

**测试目标**：人、车、骑行者、锥桶，只看正面。记录衣着／车身颜色、目标尺寸和锥桶反光条情况；同一轮对比使用同一目标。

**录包回放**：

- 从近到远连续录包，逐步改变目标与 LiDAR 的距离，保持正面朝向和视场内方位基本一致，避免其他物体遮挡。
- 按 5m 档位检查并短暂停留；距离取目标 ROI 点云的代表距离，测量口径保持一致。目标不出点时，使用地面标记或独立测距记录所在位置。
- 回放先看单帧，再看连续片段。逐档记录轮廓连续可分辨、间歇可分辨或不可分辨，不能用长时间累积补成的轮廓代替单帧表现。
- 临界处再靠近、远离一次，保留最后连续可分辨档位与后一档的对照；若场地结束时仍可分辨，记作「至少达到该距离，受场地限制」。

**观察与判定**：目标必须具备可辨轮廓，几个孤立点不算有效。只在部分帧可辨时记录为间歇可分辨，不计入连续有效距离。报告按 5m 档位给出结果，避免把档位读数写成更高精度的测量。

**复核要点**：排除视场边缘、近场盲区、遮挡和显示累积影响。不同衣着、车身材质或光照的结果分别记录；本项不评价侧面与背面。

**报告内容**：四类目标的尺寸／外观、最远连续可分辨档位、后一档表现、复测结果、场地上限；附临界前后同视角截图、包名和相对时间段。

## 2. 测距精度

**基本原理**：测距随机误差及通道差异会让平面点云呈现厚度。现场先用厚度评价点云离散程度，观察其随距离的变化；墙面薄并不能证明没有整体偏移。若要评价绝对测距偏差，需另加独立距离真值及其测量不确定度。

**测试场景**：平整、无纹理起伏的墙面和清晰墙角。选择非玻璃、非强反墙体，尽量保持接近正入射；避开墙面边缘、门窗、管线和墙角混合像素区。

**录包回放**：

- 保持安装姿态，靠近或远离墙面、墙角并录包；在 10、20、30m……附近停稳，保留静止片段，距离从目标点云读取。
- 使用相同 ROI、单帧显示、点大小和视角。从侧视图看平面厚度，墙角两面墙分别检查，不把拐角混合点纳入墙面统计。
- 有数据处理条件时，对每个静止帧独立拟合平面，计算点到平面的有符号残差，报告 P95−P5 厚度、标准差、ROI 点数与有效帧数；拟合／剔除规则固定并保留。
- 在连续帧中检查厚度是否稳定、有无通道分层，并记录变稀／缺点。只有目视结果时标注「目视估计」，不从截图点大小推算厘米值。

**观察与判定**：比较不同距离下相同统计口径的厚度与稳定性。每帧重新拟合后的残差主要反映平面内离散，不能用它证明绝对距离正确，也不能直接当作厂家的测距精度指标。

**复核要点**：运动畸变、安装振动、墙体不平、斜入射和跨帧累积都会使墙面变厚。发现整体偏移时另做真值对照，不能沿用「无偏移」假设；未做真值检查时在报告中写明。

**报告内容**：按每 10m 一行记录点云距离、ROI／统计方法、厚度、通道分层、墙角表现、稀疏／缺点、有效帧数；附侧视截图与静止片段时间段，注明绝对偏差是否验证。

## 3. 强反鬼影

**基本原理**：反光物的强回波可能引起接收饱和、杂散光或串扰，在真实物体之外形成「鬼影」，也可能使轮廓向外膨胀。实际位置与形态依设备光学结构及处理策略而变，不能仅凭点云确定具体成因。

**测试物体**：反光交通牌、车辆车牌、带反光条的锥桶。优先选择背景空旷、能确认异常位置没有实物的场景。

**录包回放**：

- 先录不含强反目标的背景，拍摄现场照片；随后对着目标连续录包，缓慢靠近或远离。
- 小幅改变方位，让目标经过视场中央和两侧，关键位置短暂停留，记录点云中的目标距离与方位。
- 回放对照真实目标的边界，检查轮廓外膨胀及其他位置的成团假点，记录它们在连续帧中的存在情况。
- 可移动目标时，将其移出视场再录背景；固定标牌则改变观察方向，检查异常是否随强反目标的出现而变化。

**观察与判定**：分别记录「轮廓膨胀」与「异位鬼影」，不把二者混为一项。成团假点必须有现场无实物的证据；单帧出现且不能复核时记作待复核。

**复核要点**：确认不是牌杆、背景物体或其他回波。对比厂家滤波／回波模式时单独录制并记录设置，不能把不同处理后的结果直接混比。

**报告内容**：强反物种类、距离和方位、膨胀／鬼影位置与范围、偶发或持续、移出视场后的变化；附现场照片、基准与异常截图、相对时间段。

## 4. 拖尾

**基本原理**：激光光斑扫过物体边缘时，可能同时覆盖近处前景与远处背景，混合回波被解算到两者之间，形成本应为空的「拉丝点」或粘连点。这种边缘现象应与运动畸变及跨帧累积拖影区分。

**测试物体**：柱子、灯杆、锥桶或木板边缘，后方选墙面，前后留几米间距。确认两者之间无枝叶、栏杆等实物。

**录包回放**：

- 拍照记录前景、背景和空隙，连续录包，缓慢靠近或远离，并小幅改变观察方向。
- 中途停稳，固定设备与目标，保留静止片段；距离由前景和背景各自的点云读取。
- 使用单帧侧视或俯视图检查边缘到背景之间的桥接点，逐帧确认静止状态下是否仍存在。
- 改变前后景间距或让边缘离开原光束方向，观察拉丝位置和长度是否随几何关系变化。

**观察与判定**：静止单帧中仍有位于空隙的点，才支持边缘混合回波的判断。报告区分零散假点与连续粘连；长度沿前后景方向读取，不以截图像素代替实际尺度。

**复核要点**：若仅运动或累积显示时出现，优先检查运动补偿、时间同步和显示累积，不直接归因于硬件拖尾。

**报告内容**：前景／背景、各自距离与间距、拖尾位置与长度、零散或连续、静止是否存在、变换几何后的结果；附照片、静止单帧截图与时间段。

## 5. 玻璃

**基本原理**：玻璃会透射和反射激光，玻璃表面可能不出点而后方物体仍可见；反射后的多路径还可能产生异位回波。透射与反射比例取决于玻璃类型、波长及入射角，不能概括成固定角度必然可见或不可见。

**测试物体**：玻璃门、落地窗、玻璃围挡。记录是否贴膜、镀膜或多层；优先选择后方有清晰物体的位置，也可放置锥桶。

**录包回放**：

- 拍照确认玻璃、门框及后方目标的位置；连续录包，缓慢靠近或远离，再从正对变为斜向观察。
- 分别检查玻璃平面附近、后方目标和其他空间区域的点，固定回波模式和显示设置。
- 门框、窗框和后方目标的点不计入玻璃表面。观察不同距离／方向下表面点是否连续。
- 可移动后方目标时改变其位置，检查可见点或疑似镜像是否随之移动，并用现场情况复核。

**观察与判定**：分别记录玻璃表面出点、后方目标可见与反射鬼影；三者可以同时存在。看到后方目标不等于玻璃障碍物被可靠检测。

**复核要点**：排除玻璃上的贴纸、污渍、门框与窗框。疑似镜像需结合现场几何及角度变化判断；没有证据时写「疑似」并保留片段。

**报告内容**：玻璃类型、距离／方向、表面点连续性、后方目标可见情况、鬼影位置及复核结果；附现场照片、不同角度截图和时间段。

## 6. 潮湿地面与积水

**基本原理**：水膜与水面可能改变反射方向，使地面回波变弱或缺失；反射路径也可能产生不对应实物的点，包括地面下方伪点。不同路面、入射角和水层状态的表现不一定相同。

**测试场景**：雨后停车场、厂区水泥地、沥青浅水洼。尽量选择同种路面上相邻的干燥、湿润和积水区域，记录湿区范围。

**录包回放**：

- 保持实际安装高度和姿态，先录干燥基准，再缓慢靠近或经过湿区，关键位置停稳。
- 拍照记录路面材质、干／湿／积水边界和周边车辆、柱子等物体。
- 回放使用同尺度俯视与侧视图，比较相近距离、相近入射角处的地面点，检查减少、断裂与地面下方异常点。
- 对照周围物体，检查异常是否位于无实物位置；条件允许时在路面干燥后复采同一位置。

**观察与判定**：地面缺点与反射伪点分别记录。仅比较湿区和远处干区不足以归因于积水，应尽量控制距离与入射角。

**复核要点**：先检查地面拟合、安装俯仰角与坐标变换；地面下方的点也可能来自外参或姿态错误。窗口被雨水打湿时单独记录，避免混入窗口污染影响。

**报告内容**：材质、干湿状态、观察距离／方向、缺点位置与范围、伪点及复采结果；附干湿对照截图、现场照片和时间段。

## 7. 雾与喷雾

**基本原理**：水滴对激光的散射可能产生空气回波，同时削弱后方目标的回波，使目标点云变稀或消失。自然雾和局部喷雾的粒径与空间分布不同，不能把喷雾档位直接换算成气象能见度。

**测试场景**：自然晨雾、园林喷雾或可控水雾。用车辆或锥桶作固定目标，自然雾与喷雾分别记录；无能见度仪器时仅描述现场现象。

**录包回放**：

- 自然雾中缓慢靠近或远离目标，记录距离与现场照片；若有能见度测量，记录仪器、位置和时间。
- 喷雾测试固定设备与目标，连续录下开启前、开启后和消散过程，尽量保持窗口干燥。
- 回放在固定目标 ROI 中检查点数和轮廓连续性，同时看空气中新增的噪点或成团回波。
- 记录窗口是否湿润；若湿润，另录清洁／干燥窗口后的片段，再判断空气水雾和窗口水滴各自的影响。

**观察与判定**：分别描述目标点损失与空气假点。可报告同 ROI、同帧口径的点数变化，但没有受控浓度或能见度时不作天气等级排名。

**复核要点**：记录回波模式和厂家雨雾滤波／标签设置。局部水柱、喷嘴等实物不算空气噪点；过滤后的干净点云也不代表目标回波未受影响。

**报告内容**：自然雾／喷雾、目标距离、可用的环境记录、目标点变化与连续性、空气噪点范围、窗口湿润情况及恢复过程；附同 ROI 对照截图、照片和时间段。

## 8. 雷达窗口脏污

**基本原理**：窗口上的水滴、泥点或浮尘可能遮挡、衰减或散射发射与接收光路，产生局部缺点、目标变稀或近场异常点。影响区域与污染位置、设备光路有关，不能假设每个污点都对应固定形状的盲区。

**测试脏污**：水滴、可清除的泥水飞溅与浮尘。按厂家允许的方法处理与清洁，保留污染位置和程度的照片；不使用可能刮伤或损坏镀膜的材料。

**录包回放**：

- 固定设备和车辆／锥桶，先确认窗口清洁，录制基准并拍摄窗口照片。
- 连续记录「干净 → 少量脏污 → 脏污增加 → 按厂家方法清洁后」，每个阶段停留并留照片与时间标记。
- 在相同 ROI 和回放设置下比较目标轮廓、缺点方向、近场异常点，观察清洁后是否恢复。
- 同时保存可用的脏污／遮挡诊断告警；无告警与点云正常分开记录。没有诊断能力时标注「不支持」或「未采集」。

**观察与判定**：用同位置的干净与污染片段对照，并以清洁后的恢复验证关联。污染照片用于描述状态，未测量的面积比例不写成精确覆盖率。

**复核要点**：清洁后仍不恢复时，检查残留水膜、设备状态与数据链路，再次采集；不把未恢复现象简单解释为可逆遮挡。

**报告内容**：脏污种类、位置、程度、目标变化与缺点区域、告警及触发时刻、清洁后恢复情况；附四阶段点云对照、窗口照片和时间段。

## 报告模板

每次评测保存一份条件表与逐项结果。正文下载包中保留此模板，可直接复制填写；「未测试」与「待复核」也必须保留。

| 字段 | 填写内容 |
| --- | --- |
| 测试标识 | 日期、地点、人员、设备型号／序列号、固件与驱动版本 |
| 配置与环境 | 安装、扫描／回波／滤波设置、目标、天气、光照、窗口状态 |
