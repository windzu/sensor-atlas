# Sensor Atlas

**自驾与机器人传感器指南**

介绍自主系统中常见传感器的基本原理、应用场景和现场评测方法，通过原理动画帮助理解，通过录包与回放保留评测证据。

- [展示网站](https://windzu.github.io/sensor-atlas/)
- [LiDAR 硬件评测专题](https://windzu.github.io/sensor-atlas/lidar.html)
- [LiDAR 硬件评测标准正文](content/lidar/hardware-evaluation.md)

## 首个专题：LiDAR 硬件评测

包含八项轻量现场测试，以及统一采集条件、判定与复核约定、报告模板：

1. 有效检测距离：人、车、骑行者、锥桶的正面目标，按 5m 档位记录连续可分辨／间歇可分辨／不可分辨。
2. 测距精度：墙面与墙角，按 10m 检查平面离散程度；绝对测距偏差需独立真值。
3. 强反鬼影。
4. 拖尾。
5. 玻璃。
6. 潮湿地面与积水。
7. 雾与喷雾。
8. 雷达窗口脏污。

每项包含基本原理、常见目标／场景、录包回放步骤、观察判定、复核要点和报告内容。正文中的距离档位与复核方法是项目约定，验收阈值应按设备与应用场景事先确定。

首页与八项评测均使用 low-poly 三维场景，统一奶油色背景、薄荷绿面片地形和珊瑚红雷达。各项目分别呈现行人／车辆／骑行者／锥桶、墙角、反光牌、前景边缘、玻璃、湿区、空气水雾和污染窗口。展示页采用暖纸色底、轻量导航与分层阅读排版。

评测场景附同步点云观察窗，支持目标选择、条件参数、基准对照、观察视角，以及「发射扫描 → 回波返回 → 点云成像」分阶段演示。桌面可拖动旋转，键盘可用方向键微调；移动端保留视角按钮和纵向滚动，系统减少动态效果设置下默认暂停。

动画采用确定性的几何与点云示意，不是物理标定的传感器仿真，也不代表某一型号的实测结果或性能承诺。八个评测共用一个 WebGL 渲染器，仅绘制当前可见场景；不支持 WebGL 时回退至 Canvas 几何视图。

Three.js 固定为 0.186.1，构建时将运行时与许可证复制到本地静态资源目录，无运行时 CDN 请求。视觉母本为 [Karim Maaloul 的 The Aviator](https://tympanus.net/Tutorials/TheAviator/)，场景模型与动画在本项目内重新编写。

## 内容维护

专题正文维护在 `content/lidar/hardware-evaluation.md`。构建脚本从正文生成页面内容，保证展示页与标准正文一致。

- `content/`：专题 Markdown 正文。
- `web/`：页面模板、样式及原理动画。
- `web/assets/scene-models.js`：多边形场景造型与表面采样。
- `web/assets/scene-data.js`：各项点云变化的定性规则。
- `web/assets/lowpoly-scene.js`：共用 3D 渲染、视角、运动与观察窗。
- `tests/`：各类评测现象与点云数据的约束验证。
- `scripts/`：构建与预览脚本，构建时包含固定版本的 Three.js 本地资源。
- `docs/`：生成后的 GitHub Pages 静态页面。

修改正文或页面源码后运行 `npm run build`，提交源码与生成的 `docs/`。GitHub Pages 从 `main` 分支的 `/docs` 发布。用 `npm run check` 检查脚本语法和生成文件一致性，`npm test` 验证场景现象与数据约束，`npm run preview` 启动本地预览。

## 案例与贡献

欢迎通过 Issue 或 Pull Request 补充传感器专题、原理说明、现场测试案例及纠错。提交实测案例时附测试条件、现场照片、点云截图或短片段，并明确区分原理示意与实测结果。

页面当前提供原理动画和测试方法，尚未包含自行采集的实测案例。引用资料的链接保留在专题正文和展示页面中。
